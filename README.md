# Login Form

A clean, responsive login form built using HTML, CSS and JavaScript.

This repo contains a small front-end project demonstrating a modern, accessible login form layout with visual styling and simple client-side validation.

## Features

- Responsive layout that adapts to desktop and mobile widths
- Styled inputs with focus states
- Client-side form validation (basic)
- Simple and easy-to-read HTML/CSS structure suitable for learning and customization

## Technologies

- HTML
- CSS
- JavaScript

## Files

- `index.html` — the login page
- `style.css` — styling for the form and layout
- `Screenshot 2024-07-27 134058.png` — project screenshot
- `digital-painting-mountains-moon.jpg` — background/illustration image included in the project

## Usage

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Login-Form-53.git

2. Open `index.html` in your browser (double-click or right-click → Open with → Browser).

No build tools or dependencies required — this is plain static HTML/CSS/JS.

## Customization

- Edit `style.css` to change colors, spacing, and typography.
- Modify `index.html` to add or remove form fields.
- Add real authentication by wiring the form submission to a backend endpoint.
